# Mini Banka Uygulaması

Python ve SQLite ile geliştirdiğim basit bir banka uygulaması.

## Özellikler
- Müşteriler, hesaplar ve işlemler için ilişkisel veritabanı tasarımı
- Bakiye görüntüleme ve para yatırma
- Hatalı tutar ve olmayan hesap kontrolleri
- Parametreli SQL sorguları (SQL injection'a karşı)

## Kullanım
1. `python veritabani.py` ile tabloları oluştur
2. `python banka.py` ile uygulamayı çalıştır

## Planlanan geliştirmeler
- Para çekme
- Hesaplar arası havale
- Aylık işlem raporları (GROUP BY)

## Kullanılan teknolojiler
Python, SQLite, SQL (JOIN, GROUP BY)
